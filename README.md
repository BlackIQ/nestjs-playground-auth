# Authentication API

A simple REST API built with NestJS for learning backend development concepts.

This project is the first step of the **NestJS Playground Learning Path**.
The goal is to understand the core architecture of NestJS by building a simple CRUD application using Prisma and PostgreSQL.

## Project Structure

This project consists of:

- Backend: NestJS REST API

## Learning Goals

### Backend (NestJS)

The backend focuses on understanding the fundamentals of the NestJS framework and modern backend development.

#### Topics

- NestJS Modules
- NestJS Controllers
- NestJS Services
- Dependency Injection
- User Registration
- User Authentication
- JWT (JSON Web Token)
- Access Tokens
- Password Hashing
- Protected Routes
- Authorization
- Authentication Dependencies
- REST API Design
- HTTP Methods
- Prisma ORM
- Prisma Client
- Prisma Migrations
- Database Integration
- HTTP Exceptions
- HTTP Status Codes

## Features

Users can:

- Register a new account
- Log in with email/username and password
- Receive an access token
- Access protected endpoints
- View their own profile
- Update profile information
- Change their password
- Log out from the application

## About Playground

**Playground** is a learning project series created to practice modern web development by building small full-stack
applications.

Each project focuses on introducing new concepts step by step, from basic CRUD operations to more advanced topics like
authentication, database relationships, and real-world application architecture.

The main goal is learning through building.
